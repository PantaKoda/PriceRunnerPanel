# Rust proof of concept vs .NET 0.4.7 — measured 2026-11-02

Both apps ran on this machine from the same copy of the watchlist (8 pins, 341 KB state.json, cached
thumbnails), driven by the same scripts. The .NET side is the 0.4.7 test build (software rendering,
ReadyToRun, the same code as the release). The Rust side is `rust-poc/` built with `cargo build --release`.
Memory is read from the process (private bytes and working set); CPU is the process's total over 10 s.

## What the proof of concept is

`../README.md` lists the stack and the features. In short: Slint for the UI (markup close to AXAML,
drawn on the CPU like 0.4.7, rows created only when on screen), blocking HTTP on short worker threads, no
async runtime, the same PriceRunner endpoints, the same state.json (round-tripped: the Rust app ran a full
8-pin check and wrote the file; the .NET build loaded it and showed identical cards, see the two watchlist
screenshots), the same thumbnail cache files, tray icon and menu, toasts, single instance, `--startup`.

Not ported: the self-updater and the Start menu shortcut (about 1 100 lines of C#), tooltips, the
spinning/breathing animations, UI Automation names. The CPU renderer has no window transparency on Windows,
so the panel is an opaque window whose corners Windows 11 rounds (with its own shadow); card shadows are
plain borders. The look is otherwise the same (compare `rust-watchlist.png` with
`dotnet-watchlist-same-data.png`).

## Where the Rust version is worse, and what it would cost

- **Watchlist scrolling costs more CPU** (11.5 % vs 7.3 % of one core). Each card's sparkline is a vector
  path that Slint rasterises again every frame while it moves. Rendering sparklines to small images once
  per price check would bring this well under the .NET figure; about a day's work.
- **Startup cost moved to the build:** a clean release build takes 2.5 minutes (incremental builds about
  1 minute). The .NET build is faster to iterate on.
- **Two codebases, one of them in a language the project does not use today.** The port of everything
  shown here took one session; finishing it (updater with staged apply, shortcut, tooltips, accessibility,
  edge cases such as rate limiting and DPI changes) and testing it to release quality is a few more days,
  plus ongoing maintenance in Rust rather than C#.
- **Slint licensing:** desktop apps can use the royalty-free licence or GPLv3; either must be chosen and
  stated in the repository.
- **Windows 10 shows square corners** (DWM corner rounding is a Windows 11 API).

## What stays the same for the user

Same tabs, cards, chips, verdicts, filters, keyboard shortcuts, tray behaviour, notifications, data file and
data folder layout. A watchlist moves between the two apps without conversion.
